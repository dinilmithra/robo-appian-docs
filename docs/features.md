# Available features

RoboAppian lets an automation engineer interact with Appian controls using their business labels.

| Feature | What you can do |
| --- | --- |
| Text fields | Enter values and send supported keyboard actions. |
| Dates | Enter a date and move focus away to commit the value. |
| Dropdowns | Select an actual choice by text or position; search supported dropdowns. |
| Radio buttons and checkboxes | Set and check selections. |
| Buttons, links and tabs | Navigate and perform application actions. |
| Menus | Follow the parent and child menu path. |
| Dialogs | Work with supported controls in a dialog. |
| Grids and datasets | Locate rows, columns and cells; interact with supported cell controls. |
| Verification | Check visibility, selected values and required business results. |
| Execution evidence | Review enabled images, page captures and structured evidence. |

Use only controls supported by your installed release. An unsupported control
requires help from your automation team; a similar-looking control may behave differently.
