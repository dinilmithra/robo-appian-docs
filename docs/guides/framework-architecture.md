# How the libraries work together

`robo-automation` provides browser sessions, pytest integration and evidence.
`robo-appian` provides named Appian controls for writing application tests.
RoboTest Studio provides visual recording, review and test generation.
Your consumer project owns application settings, test data and business tests.

Install the libraries needed by your project and use their documented public
interfaces. Internal architecture and maintainer documentation remain in the
private implementation repositories.
