# Use execution evidence

Enable evidence in your test project before running the testcase.
Choose images to see the page, HTML for a captured page and JSON for structured
execution details. These formats can be enabled separately.

Choose after-action evidence for routine review or before-and-after evidence to
compare a supported action's effect. Failure evidence has its own settings.
A before-and-after mode can enable capture even when normal action capture is off.
Disable both action modes when you do not want action evidence.

Review the failed step, the actual page and the approved expected result together.
An unexpected sign-in or warning page usually means the test never reached its
intended starting point. More waiting will not complete a missing entry step.

Evidence can include application data. Use approved test data and share captures
through your team's approved channels. Enabling evidence later cannot recover an
uncaptured earlier step.

See [capture options](https://dinilmithra.github.io/robo-automation-docs/guides/action-snapshots/).
